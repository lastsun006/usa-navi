## 2. 画面一覧と役割

### 画面1: トップ画面（ユースケース選択）
**URL**: `/`

| 項目 | 内容 |
|------|------|
| 目的 | ユーザーの状況を絞り込み、適切なチャットへ誘導する |
| 主要要素 | ・サービスロゴ/キャッチコピー<br>・5つのユースケースカード<br>・「今すぐ相談する」ボタン（全般チャット） |

| UI方針 | カード形式（アイコン+タイトル+サブコピー）、縦スクロール、タップエリア大きめ |

```

```

## 4. 情報の種別と管理方針

### 4.1 静的コンテンツ（自社管理）
**定義**: 変化が少なく、知識として持てる情報

| 情報 | 例 | 管理方法 |
|------|-----|---------|
| 基本的なフロー | レストランの入店〜会計の流れ | Markdownファイル / JSONナレッジ |
| 英語フレーズ | 注文・チップ・入国審査の定番フレーズ | `english-phrases.json` |
| チップの相場感 | 15-20%が一般的など | `knowledge-base.json` |
| 子連れ注意事項 | ベビーカー持込可否、ハイチェアの場所 | `knowledge-base.json` |
| 緊急時テンプレ | 救急車の呼び方、警察への伝え方 | `knowledge-base.json` |
| ディズニー基本ルール | Genie+の仕組み、Lightning Laneの種類 | `knowledge-base.json` |

**更新頻度**: 月次確認（料金変更・ルール変更のチェック）

---

### 4.2 AIで生成する情報
**定義**: ユーザーの状況に応じてカスタマイズが必要な情報

| 情報 | 例 | AI活用理由 |
|------|-----|-----------|
| 状況別の行動アドバイス | 「子ども2人連れでLAX午後着」の場合の移動 | 組み合わせが無限 |
| 英語フレーズの文脈化 | 「菜食主義の人向け注文フレーズ」 | 文脈依存 |
| トラブル対応の手順 | 「財布なくした、ホテルはこちら」の状況 | 状況依存 |
| 質問への自由回答 | ユーザー独自の質問 | 予測不能 |

**注意**: AIが生成する情報は必ず「最新情報はご確認ください」を付記する

---

### 4.3 外部データ依存（MVP外、Phase 2以降）
**定義**: リアルタイム性が必要な情報

| 情報 | 外部ソース | MVP方針 |
|------|-----------|---------|
| Uber概算料金 | Uber API | 「$25〜$40程度」と幅で回答（静的） |
| ドジャースチケット価格 | Ticketmaster API | 「公式サイトで確認を」と誘導 |
| ディズニー混雑予測 | ThemeParks.wiki API | 「一般的な混雑情報」を静的提供 |
| 天気 | OpenWeatherMap | MVP除外（「LAの天気はおおむね晴れ」と固定) |

## 7. 緊急時テンプレ

| 状況 | 対応フロー | 英語フレーズ |
|------|------------|------------|
| 救急 | 911に電話 → ホテルスタッフへ連絡 | "Call 911, please. It's an emergency." |
| 盗難・紛失 | 警察レポート入手 → クレカ停止 → 大使館 | "I'd like to report a theft." |
| 子どもが迷子 | スタッフへ即伝達 | "My child is lost. Can you help me?" |
| 体調不良 | ホテルスタッフ → Urgent Care | "I need to see a doctor. Where is the nearest urgent care?" |
| パスポート紛失 | 日本領事館（LA: +1-213-617-6700） | 電話番号を即提示 |

## 8. 子連れ追加情報

### 年齢別対応
| 年齢 | 移動 | 食事 | アクティビティ | 注意点 |
|------|------|------|-------------|--------|
| 0-2歳 | ベビーカー必須、機内ミルク準備 | ベビーフード持参推奨 | 限定的 | 時差ぼけ対策、気温差 |
| 3-5歳 | ベビーカーまたは抱っこ | ハイチェア依頼可 | ディズニーJr.系 | 日差し・水分補給 |
| 6-10歳 | 徒歩メイン、疲れやすい | キッズメニューあり | ほぼ全て対応 | 迷子防止対策 |
| 11歳以上 | 問題なし | 大人メニューOK | 全対応 | スマホ管理 |

### ディズニーランドの子連れポイント
- Baby Center（授乳・おむつ替え）の場所
- Rider Switch（子どもが乗れないアトラクションで親が交互に乗れる制度）
- 身長制限のあるアトラクション一覧
- 子連れにおすすめのエリア・アトラクション
