## 1. プロダクト概要

### Who（誰向けか）

**プライマリターゲット**
- 初めてアメリカ（主にLA）へ旅行する日本人
- 英語に不安がある人（TOEICスコア低め、会話未経験）
- 個人・家族旅行者（ツアーでなく自分で動く）

**セカンダリターゲット**
- 子連れ旅行者（2〜10歳の子ども連れ）
- 学生・若年層の初海外旅行者

**対象外（MVP）**
- アメリカ旅行経験者（2回目以降）
- ビジネス旅行者
- ヨーロッパ・アジア旅行者

---

### Why（何を解決するか）

**ユーザーが抱える不安と課題**

| 課題 | 現状の回避策 | 問題点 |
|------|------------|--------|
| 英語が話せなくてパニック | Google翻訳でその場対応 | 翻訳だけでは状況判断できない |
| 空港での移動方法が分からない | 事前にブログを読む | 情報が古い・個人差が大きい |
| チップいくら？どこで払う？ | 都度ネット検索 | 情報バラバラ、その場で使えない |
| 子連れでレストランに入れるか不安 | 諦める・ファストフードに変更 | 体験の質が下がる |
| トラブル時どうすれば | 日本人旅行者SNSコミュニティで質問 | 即座に答えが出ない |

**このプロダクトが解決すること**
- 「今この状況でどうすればいいか」を日本語で即答
- 英語フレーズを"そのまま使える形"で提示
- ユースケース特化の深い知識で一般論を超えた回答
- 旅行前の準備〜現地での行動〜帰国まで一貫サポート

## 2. MVPスコープ定義

### やること（MVP）

**コア機能**
- [ ] ユースケース選択画面（5カテゴリ）
- [ ] チャット形式でのQ&A（Claude API接続）
- [ ] 英語フレーズのコピー機能
- [ ] クイックリプライ（よくある質問をボタンで選択）
- [ ] 静的ガイド画面（各ユースケースの事前知識）
- [ ] スマートフォン最適化UI

**5つのユースケース（MVP）**
1. LAX到着〜ホテル移動
2. ドジャース観戦
3. アメリカのレストラン利用
4. 子連れ旅行（ディズニー含む）
5. ディズニーランド/DCA（アナハイム）

### やらないこと（MVP除外）

| 機能 | 除外理由 | 対応フェーズ |
|------|---------|------------|
| ユーザー登録・ログイン | 検証速度優先 | Phase 2 |
| 課金・プレミアムプラン | 価値検証が先 | Phase 3 |
| 旅程作成・保存 | 複雑度が高い | Phase 3 |
| リアルタイム情報（天気・交通） | 外部API連携コスト | Phase 2 |
| 音声入力・翻訳 | スコープ外 | Phase 4 |
| 地図連携 | 複雑度が高い | Phase 2 |
| 多言語対応（日本語以外） | MVP対象外 | Phase 4 |
| B2B API提供 | 個人向けを先に | Phase 4 |

## 3. コア機能詳細

### 3.1 ユースケース選択画面

- 5つのカテゴリをカードUIで表示
- 各カードに：アイコン、タイトル、サブコピー（例「LAX着いたら何をすべき？」）
- タップでチャット画面へ遷移

### 3.2 チャット画面

- LINE風のチャットUI
- 最初に「状況確認質問」をAIが自動送信（例「いつ到着しますか？ターミナルは？」）
- クイックリプライボタン（頻出質問をボタン化）
- 英語フレーズ回答時はコピーボタン付きカード形式
- 長い回答はアコーディオン展開

### 3.3 静的ガイド（Pre-Trip Guide）

- 旅行前に読むコンテンツ（チャット不要）
- 各ユースケース1ページ分
- セクション: 基本知識・注意点・英語フレーズ集・チェックリスト

### 3.4 英語フレーズ機能

- 回答内にインライン表示（日本語 → 英語）
- コピーボタンで即コピー
- 発音ガイド付き（カタカナ）

## 5. 主要ユースケース詳細

### UC-01: LAX到着〜ホテル移動

**ユーザーの状況**
- 14〜17時間のフライト後、疲弊した状態でLAXに着いた
- 荷物受取、入国審査、移動手段、ホテルチェックインを自力でこなさなければならない

**主な質問パターン**
- 入国審査で何を言えばいい？
- Uberはどこで乗れる？
- タクシーはぼったくられない？
- ホテルまでいくらかかる？
- 子連れだと何か違う？

**AI回答の重点**
- ターミナル別のUber乗り場情報（具体的）
- 入国審査の英語フレーズ（観光/滞在期間/ホテル名）
- 到着から最初の1時間の行動ステップ（順番付き）

---

### UC-02: ドジャース観戦

**ユーザーの状況**
- ドジャーズを生で観たい。でもスタジアムのルール、食事、移動が全部謎

**主な質問パターン**
- チケットはどこで買う？
- スタジアムへの行き方は？
- 持ち込み禁止は何？
- 食事どうする？（注文方法、値段感）
- 大谷選手を見るにはどの席が良い？

**AI回答の重点**
- 公式チケット vs 二次流通の違いと注意点
- スタジアムへのUber/Lyftルート
- 入場ゲートでの手荷物検査の流れ
- 座席エリア別の解説（特に日本人に人気のエリア）

---

### UC-03: アメリカのレストラン利用

**ユーザーの状況**
- アメリカのレストランに入るのが怖い。席の取り方、注文、チップが全部謎

**主な質問パターン**
- 入ったらまず何をする？
- チップは何%？いつ払う？
- 「for here or to go?」って何？
- 英語でどう注文すればいい？
- 子連れOKなレストランの見分け方は？

**AI回答の重点**
- 入店〜会計の全フロー（ステップ付き）
- チップ計算の具体的な方法
- よく使う注文フレーズ（カタカナ発音付き）
- アレルギー・食制限の伝え方

---

### UC-04: 子連れ旅行

**ユーザーの状況**
- 子ども連れでアメリカ旅行。何が心配かも分からないくらい不安

**主な質問パターン**
- ベビーカーは持って行くべき？
- レストランで子ども用椅子はある？
- 子ども向けのアクティビティは？
- 薬（体温計・常備薬）は持参すべき？
- 緊急時（子どもが熱を出した）はどうする？

**AI回答の重点**
- 年齢別（乳幼児/幼児/小学生）の具体的アドバイス
- 持ち物チェックリスト（子連れ版）
- 緊急医療機関の探し方・フレーズ
- ディズニーランドでの子連れ攻略

---

### UC-05: ディズニーランド/DCA

**ユーザーの状況**
- アナハイムのディズニーランドへ行く。事前予約、待ち時間対策、食事が分からない

**主な質問パターン**
- Genie+は必要？
- Lightning Laneはどう使う？
- 子連れで絶対乗るべきアトラクションは？
- 混雑を避けるには？
- パーク内の食事、どこがおすすめ？

**AI回答の重点**
- 事前予約の流れ（アプリのダウンロードから）
- Genie+/Lightning Laneの仕組みを日本語で丁寧に
- 子どもの年齢別おすすめアトラクション
- 混雑カレンダーの読み方

## 7. リスクと制約

| リスク | 影響度 | 対応策 |
|--------|--------|--------|
| AI回答の精度不足 | 高 | 知識ベース整備 + プロンプトチューニング |
| 最新情報の陳腐化（料金・ルール変更） | 中 | 「最新情報はご確認ください」免責表示 + 更新フロー整備 |
| Claude APIコスト増大 | 中 | トークン最適化 + 課金フェーズで回収 |
| ユーザーが課金しない | 中 | Phase 1は無料、価値証明が先 |
| 競合サービスの台頭 | 低〜中 | ユースケース特化の深さで差別化 |
| 医療・緊急情報の誤案内 | 高 | 免責表示 + 専門家への誘導テンプレ必須 |

---

## 8. 前提条件・制約

- スマートフォン（iOS/Android）ブラウザで動作すること（アプリ不要）
- 日本語のみ対応（MVP）
- オフライン非対応（通信必須）
- 個人情報収集はMVPでは最小化（名前・メールのみ、Phase 2以降）
